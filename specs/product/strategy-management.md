# Управление стратегиями поиска

Стратегии глобальны: выбор пространства не фильтрует список. Карточки не содержат
тегов. Доступны создание, просмотр, редактирование и удаление с подтверждением.

Control API принимает POST /api/v1/strategies, PUT и DELETE
/api/v1/strategies/{id}. Ответ 202 подтверждает команду. Состояние интерфейса
обновляется только событиями strategy.created, strategy.updated и strategy.deleted
после записи транзакции. Начальное состояние загружается через bootstrap.

Удаление используемой бенчмарком стратегии возвращает 409. Отсутствующий объект
возвращает 404. Изменение стратегии глобально, о влиянии на связанные бенчмарки
редактор предупреждает. Схема хранения не меняется.
